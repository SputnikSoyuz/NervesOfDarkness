Same for Revealed Title

| Rumour Reveal Location           | Rumour Description                                                                                    |
| -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Enclosed Caverns Entrance        | I found a pathway blocked by a series of crystals. A sign with a jackhammer is found next to it.      |
| Attempt to Break with Jackhammer | I tried to use the jackhammer on the crystals themselves. It cannot break the crystals directly.      |
| Jackhammer Success               | Using the jackhammer on the hard floor made a screeching sound that was enough to break the crystals. |
| Enclosed Caverns Media Disc      | A Display Device in the caverns displays a light crystal in the borehole.                             |

The Enclosed Caverns is a cave within the main system of caverns on the far side of Purple Partition. Crystals block the entry to the caverns, which the player can bypass by making noise with the jackhammer item. Inside the caverns lies a clue on how to get the crystal for the Excavation Outpost.
